# JPEI - SpiderManNATB

## ¿De que trata el juego?

Juego Beat-em'up sobre Spider-Man luchando contra Fisk, que está contaminando la ciudad sin importarle las consecuencias con tal de obtener beneficios económicos.
Movimiento y combate retro con una perspectiva 2.5D.
Incluye un pequeño tutorial y el level 1, pues es una demo.
Dani se hizo lo que se pudo 🥲.

## Funcionalidades

Con titulo y todo WOW!

Spiderman ya vuelve a tener ammo del Webshooter! Por fin puede usarlo.

## Funcionalidades nuevas (tras el tag Entrega)

Las Cajas ahora dropean vida! Ya no se juega en modo hardcore se podría decir.
Más y mejores sonidos, incluyendo destruccion de caja, explosion de granada, curarse y acabar con un enemigo.
